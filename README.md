# JavaScript Algorithms & Data Structures

Solutions and exercises completed as part of the **freeCodeCamp JavaScript Algorithms and Data Structures** curriculum.

🏅 [View Certification](https://www.freecodecamp.org/certification/lordmuze/javascript-algorithms-and-data-structures)

---

## About

This repository contains my working solutions to freeCodeCamp's JavaScript challenges, covering core algorithm patterns, string/array manipulation, OOP concepts, and the five certification projects. It also includes a reference text on algorithm design thinking sourced from *The Algorithm Design Manual*.

---

## Certification Projects

These are the five required projects completed to earn the certification:

| File | Challenge |
|---|---|
| `palindrome.js` | **Palindrome Checker** — Strips non-alphanumeric characters and checks if a string reads the same forwards and backwards |
| `romannumeral.js` | **Roman Numeral Converter** — Converts an integer to its Roman numeral representation |
| `caesarcipher.js` | **Caesar Cipher** — ROT13 cipher that shifts letters 13 positions in the alphabet |
| `telephone.js` | **Telephone Number Validator** — Uses regex to validate US phone number formats |
| `cashregister.js` / `CashRegister2_0.js` | **Cash Register** — Calculates change due and returns it broken down by denomination; handles `OPEN`, `CLOSED`, and `INSUFFICIENT_FUNDS` statuses |

## Algorithm Challenges

Intermediate algorithm scripting exercises:

| File | Challenge |
|---|---|
| `fibonaccisequence.js` | **Sum All Odd Fibonacci Numbers** — Generates the Fibonacci sequence up to *n* and sums only the odd values |
| `largnoarray.js` | **Largest Numbers in Arrays** — Returns the largest number from each sub-array |
| `longestwordstr.js` | **Find the Longest Word in a String** — Returns the length of the longest word in a sentence |
| `dropit.js` | **Drop It** — Drops elements from the front of an array until a predicate function returns true |
| `steamroller.js` | **Steamroller** — Recursively flattens a nested array of arbitrary depth |
| `binaryAgent.js` | **Binary Agent** — Converts a binary string (space-separated bytes) into human-readable text |
| `charactertohtml.js` | **Convert HTML Entities** — Replaces characters like `&`, `<`, `>`, `"`, `'` with their HTML entity equivalents |
| `predTrue.js` | **Everything Be True** — Checks whether all objects in a collection have a truthy value for a given property |
| `union.js` | **Seek and Destroy / Unite Two Arrays** — Filters or merges arrays based on given arguments |
| `reduceTextAdd.js` | **Sum All Numbers in a Range** — Uses `Array.reduce()` to sum all integers between (and including) two numbers |
| `reserve.js` | **Reverse a String** — Reverses a string without using `.reverse()` directly |
| `sieve.js` | **Sieve of Eratosthenes** — Finds all prime numbers up to a given limit using the classic sieve algorithm |
| `integertest.js` | **Number testing utilities** — Exercises around number type checking and validation |
| `sa.js` | **Sum All Primes** — Sums all prime numbers up to and including a given number |
